硬件定位就是轻量。512MB 内存跑代理、推流工具、定时发布脚本够用，跑重负载的转码或采集就别考虑了。巴西节点在 WePC 的 TikTok 产品线里上线较晚，2026 年 5 月已经有对应的产品页和第三方测评，库存相对其他热门节点充足一些，下单前还是确认一下。

## 大陆直连延迟高不高，中转要花多少

巴西套餐走的是非优化国际线路，中国大陆直连圣保罗延迟高，官方和第三方测评都建议经香港、日本或新加坡中转后再用。这不是配置问题，是物理距离决定的。

## 常见问题

**巴西 IP 是原生住宅还是机房 IP？**
产品页写的是巴西原生住宅 IP，机器托管在圣保罗机房。IP 属性是住宅段，机器仍在机房里。

**2TB 是双向计费吗？**
是，上传和下载都计入。直播推流主要吃上行，视频发布上下行都不大。

**流量超了会停机吗？**
不会断线，限速到 5Mbps。5Mbps 还能跑低码率直播，高清推流不行。

**支持支付宝吗？**
支持支付宝、信用卡、PayPal，官网以澳元计价。

**能装 Windows 吗？**
官方套餐页列出的系统是 Ubuntu、Debian、CentOS 和 RockyLinux，都是 Linux，没有列出 Windows。

**退款怎么算？**

不能，一单只能用一码。
